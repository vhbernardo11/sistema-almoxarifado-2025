# Roadmap de reconstrução

## 1. Consolidação no GitHub
Objetivo: criar uma única fonte de verdade, preservar histórico, limpar a fundação e validar smoke test.

## 2. Núcleo textual limpo
Objetivo: Maestro + Pesquisador + Estrategista + Copywriter funcionando de verdade, com contratos estruturados e testes.

## 3. Memória e estado no Supabase
Objetivo: persistir Runs, Tasks, AgentResults, Artifacts e Checkpoints, permitindo retomada após falhas.

## 4. Aprovação humana + Publisher
Objetivo: implementar a barreira de aprovação e preparar a integração com Metricool sem publicação acidental.

## 5. Imagem e vídeo
Objetivo: reintroduzir mídia apenas quando houver provider confiável, fallback e qualidade suficiente.

## Regra de avanço
Nenhuma etapa avança só porque “parece funcionar”. Ela precisa ter contrato claro, testes e estado persistente no repositório canônico.
