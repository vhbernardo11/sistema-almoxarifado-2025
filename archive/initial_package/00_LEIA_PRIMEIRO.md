# Integra — Pacote inicial do projeto IntegraSquad

Este ZIP foi preparado para abrir um novo espaço/projeto chamado **Integra** sem perder o raciocínio acumulado.

## Comece por aqui

1. Abra `04_ETAPA_1_BOOTSTRAP.json`.
2. No novo espaço chamado **Integra**, envie esse JSON como contexto inicial.
3. Diga: **“Execute somente a Etapa 1 deste JSON e me conduza até o smoke test passar.”**
4. Não avance para o Maestro antes da fundação estar validada.

## Arquivos principais

- `01_CONTEXTO_CONSOLIDADO.md` — por que o projeto existe e qual foi a conclusão da investigação.
- `02_ARQUITETURA.md` — desenho do sistema.
- `03_ROADMAP_12_ETAPAS.md` — evolução planejada.
- `04_ETAPA_1_BOOTSTRAP.json` — instrução pronta para iniciar o novo espaço.
- `05_AGENTES_MVP.json` — papéis e responsabilidades.
- `06_WORKFLOW_MVP.json` — fluxo campanha → Reels.
- `07_STACK_E_REGRAS.json` — tecnologias e regras.
- `08_FONTES_E_REFERENCIAS.md` — fontes públicas usadas na investigação.
- `09_PROMPT_NOVO_ESPACO.txt` — prompt curto para colar no novo espaço.
- `10_CHECKLIST_ETAPA_1.md` — definição objetiva de “pronto”.
- `starter_code/` — esqueleto mínimo da fundação.
- `anexos/` — materiais desta conversa disponíveis no ambiente.

## Regra mais importante

Não tentar construir o “Squad completo” no primeiro dia.
Primeiro fazemos o motor funcionar; depois adicionamos especialistas, mídia, publicação, memória e dashboard.
