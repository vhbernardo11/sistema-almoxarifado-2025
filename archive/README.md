# Arquivo de preservação

Este diretório guarda o material textual preservado na Etapa 1 de consolidação.

- `initial_package/` contém o pacote inicial e o starter code original.
- `context/` contém registros de contexto usados durante o projeto.
- O projeto GitHub que foi reaproveitado ficou preservado integralmente na branch `archive/pre-integrasquad`, apontando para o último commit original antes da migração.

O arquivo binário de referência `squad100_reference.jpg` não é necessário para executar o sistema e não entra no caminho crítico do repositório; seu hash e descrição estão registrados em `context/squad100_reference.md`.
